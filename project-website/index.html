What this project is

Race analysis that stays inside the evidence boundary.

The dashboard uses FastF1-supported data such as speed, RPM, gear, throttle, brake state, DRS, position, lap times, sector times, tyres, track status, weather, stint information, and pit timing. It separates direct data, derived metrics, and heuristic interpretations so the user knows what is measured and what is inferred.

Core workflow

Lap comparison that explains the delta.

The lap analysis mode aligns telemetry by distance, then breaks the lap into meaningful sections. Instead of only showing that one lap was faster, it ranks where the time changed and connects each gain or loss to braking, throttle, speed, gear, DRS, RPM, acceleration, and racing-line evidence.

  • Total and sector delta calculations
  • Distance-aligned speed, throttle, brake, RPM, gear, DRS, and delta traces
  • Detection ranking for gains, losses, and heuristic findings
  • Track map markers and selected-finding detail

Plan mode

Strategy planner for race-shaping decisions.

Plan mode groups the race into tyre and stint decisions. It gives the strategist a fast read on average pace, best lap, stint length, compound usage, and fuel-proxy trends so alternate plans can be compared against the race that actually happened.

  • Tyre stint timeline by driver
  • Average pace and best lap per stint
  • Race pace trend and fuel-proxy comparison
  • Readable strategy tables for post-race review

Pit window intelligence

Connect pit timing, tyre phase, and traffic context.

Pit stop intelligence summarizes pit-in and pit-out timing, lane time, compound changes, and stint transitions. It helps expose when a stop protected track position, when an undercut window opened, and where pit loss changed the competitive order.

Data discipline

Clear about what the dashboard can and cannot claim.

Direct FastF1 channels

Speed, RPM, gear, throttle, brake state, DRS, position, lap timing, sector timing, tyre compound, tyre life, weather, and session context.

Derived metrics

Delta time over distance, active brake and DRS distance, speed gain, section time deltas, path deviation, and approximate acceleration.

Heuristic interpretations

Possible missed apex, early lift, coasting, throttle hesitation, and line deviation are labelled as approximate when the raw data cannot prove intent.
